# Changes made to Xovi during the event window

These are the changes Zenbit made during the ETHOnline 2026 event window to Xovi, a product whose repository remains private, published here under this repository's MIT licence so that the new parts of the extended project are open source. Taken from Xovi at commit 2754a0eb on origin/dev, 2026-09-08: the three migrations that add clip provenance columns, bind a machine-submitted clip to its credential and store a signed confirmation (`migrations/0024`, `0025`, `0027`); the ingest route through which a machine proposes a clip (`app/api/ingest/clips/route.ts`); an excerpt of the credential module with the token format, the key context and the checks the route calls (`lib/ingest/apiKey.excerpt.ts`); the event-window changes to the clip review route as a unified diff, which add the guard that refuses a reviewer who is the responsible human behind a machine credential and the signature a reviewer now provides (`app/api/verify/[id]/route.ts.event-window.patch`); and the module that builds and checks that signature (`lib/verify/confirmation.ts`).

Two kinds of text were redacted, each marked in place: comments that compared the clip route or its columns to other ingestion paths of the product, and the list of capabilities issued to credential classes other than the clip proposer, which the excerpt declares generically. The route validates a clip target against Xovi's public specimen roster through a module that is not included here, and the files import other Xovi modules, so nothing in this directory runs on its own. A further migration written during the window, 0026, is not included because it belongs to a different monitoring layer of the product and not to the agents rail; it is declared in `DISCLOSURE.md`.
