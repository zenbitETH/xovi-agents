# AI usage

Zenbit builds and maintains this repository, and uses **Claude Code** (Anthropic) to draft prose and code against the specifications in [`docs/spec/`](./docs/spec/), which are written before the code rather than derived from it. **The technical architecture and the integration with the existing Xovi codebase are Zenbit's, with no model output in them.** The video's narration is not: its text was drafted with the model and is spoken by a person, and the presentation deck the same. The video's shots, its edit and what it chooses to show are Zenbit's. This is rewritten here rather than qualified further down for the reason the UI sentence was: a categorical claim whose exception lives somewhere else is a claim a reader has no way to check. The UI and UX design was Zenbit's on those same terms until 2026-09-12, and the agents dashboard changes that: its information architecture, its copy and the layout of its sections were drafted by the model against Zenbit's design system, under a pattern skill Zenbit wrote and had audited before it was used. The design system itself, the tokens, the invariants the surface is bound to and every cut are Zenbit's, and the sentence is rewritten here rather than qualified in a row, because a categorical claim with an exception living somewhere else is a claim a reader has no way to check. The same holds for the invariant that an agent may propose and may never confirm, the decision that an agent earns no credit, the scope cuts, the evaluation numbers quoted in the README (164 frames from 13 verified clips, measured 2026-08-28: 159 correct station reads, 50 correct and 0 incorrect at frame level with 114 referred to a human, 6 of the 13 clips identified; measurements on a real bank of frames, not estimates, and pinned to a date because the bank grows), and the review that sends work back, which it does often. One example: the mitigation first specified for the self-review guard would have failed open on precisely the case it was written for, and Zenbit's review caught it, not the drafting. Protocol details in the spec, meaning the x402 header names, the anchoring call's behaviour on a repeat and the contract version deployed on the testnet, were confirmed against live networks and primary sources rather than model recall, and two of the three contradicted what the model first asserted.
