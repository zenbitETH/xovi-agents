# AI usage

Zenbit builds and maintains this repository, and uses **Claude Code** (Anthropic) to draft prose and code against the specifications in [`docs/spec/`](./docs/spec/), which are written before the code rather than derived from it. **The UI and UX design, the technical architecture, the integration with the existing Xovi codebase, and the video, voice narration and presentation deck are Zenbit's, with no model output in them.** The same holds for the invariant that an agent may propose and may never confirm, the decision that an agent earns no credit, the scope cuts, the evaluation numbers quoted in the README (164 frames from 13 verified clips, measured 2026-08-28: 159 correct station reads, 50 correct and 0 incorrect at frame level with 114 referred to a human, 6 of the 13 clips identified; measurements on a real bank of frames, not estimates, and pinned to a date because the bank grows), and the review that sends work back, which it does often. One example: the mitigation first specified for the self-review guard would have failed open on precisely the case it was written for, and Zenbit's review caught it, not the drafting. Protocol details in the spec, meaning the x402 header names, the anchoring call's behaviour on a repeat and the contract version deployed on the testnet, were confirmed against live networks and primary sources rather than model recall, and two of the three contradicted what the model first asserted.
